# Study Log - 学习记录网站

## 📖 项目简介

Study Log 是一个个人学习记录网站。

它不是普通的 ToDo 清单，而是一个围绕**上传学习成果**设计的学习记录系统。

项目的目标是模拟"每天提交作业"的过程。

每天完成学习后，用户需要拍摄作业照片上传到网站，网站负责保存、整理、统计这些学习记录，从而帮助养成坚持学习的习惯。

---

# 🎯 项目目标

- 每天上传学习成果（照片）
- 保存长期学习记录
- 查看每天学习情况
- 查看各学科学习历史
- 上传学习计划
- 统计学习数据
- 建立属于自己的学习档案

重点不是"完成任务"，而是"留下学习记录"。

---

# 💡 核心理念

整个网站围绕 **上传学习记录（Upload Study Record）** 展开，而不是 ToDo 勾选。

上传一张照片，就代表今天这一科已经完成。

统一使用：

- 已上传
- 未上传

---

# 🏠 首页（Dashboard）

首页包含：

1. 今日日期
2. 当前学习计划（可查看）
3. 今日各学科上传状态（已上传 / 未上传）
4. 今日上传统计（数量 + 进度条）
5. 今日学习记录（自动汇总已上传科目）

---

# 📚 学科页面

每个学科拥有独立页面，包括：

- 今日作业（文本输入）
- 上传图片（支持 JPG、PNG，多张）
- 图片预览
- 上传时间
- 历史记录（按日期）

---

# 📅 学习日志

按日期查看当天所有学习记录，包括各学科上传的图片。

---

# 📂 学习计划

支持上传：

- PDF
- 图片

用于保存学习计划、课程表、暑假安排等。

---

# 📊 数据统计

统计：

- 总上传数量
- 连续上传天数
- 本月上传数量
- 各学科上传次数

尽量使用卡片和图表展示。

---

# 🗓 日历

使用学习日历展示每天是否有上传记录。

点击某一天即可查看当天学习记录。

---

# 💾 数据存储

第一版使用 LocalStorage 保存：

- 上传图片
- 上传时间
- 作业内容
- 学习计划
- 学习记录
- 统计数据

刷新页面后数据不能丢失。
